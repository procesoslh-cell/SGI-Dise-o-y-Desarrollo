# Proceso funcional

El workflow base conserva las etapas definidas para Diseño y Desarrollo, pero el creador del proyecto puede retirar las que no correspondan y asignar cada tarea a una persona.

Cada tarea posee:

- Fecha de inicio y vencimiento.
- SLA visible.
- Responsable por usuario.
- Plantilla específica.
- Avances parciales.
- Checklist.
- Entregables adjuntos.
- Validación del jefe del proyecto.
