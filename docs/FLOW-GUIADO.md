# Flujo guiado simplificado

Proyecto → tarea asignada → avance parcial → entrega → validación del jefe → siguiente tarea.

El mismo dato se muestra en Mis tareas, dentro del workflow del proyecto, en Calendario y en Gantt. No existen módulos separados de Workflow, Validaciones, Documentos o Notificaciones.

Las tareas del Plan de Marketing siguen el mismo circuito:

1. El jefe del proyecto selecciona una plantilla y asigna un usuario.
2. El usuario recibe alerta interna y correo si SMTP está configurado.
3. Trabaja desde Mis tareas y guarda avances parciales.
4. Adjunta el entregable.
5. Envía a validación.
6. El jefe aprueba u observa desde Mis tareas.
